# Panel admin

Admin masuk melalui `/login` dan membuka `/dashboard`. Panel memakai sesi web, pemeriksaan role, serta token CSRF pada form perubahan. Profil admin tersedia melalui menu profil.

Dashboard menampilkan ringkasan transaksi dan omzet. Menu operasional mencakup kategori, subkategori, produk, varian, bundling, pelanggan, promo, voucher, pesanan, custom order, refund, dan laporan. Menu pelanggan mendukung tambah, ubah, dan hapus. Penghapusan ditolak jika pelanggan masih memiliki pesanan, alamat, atau custom order.
