# Katalog

Katalog publik menyediakan daftar kategori beserta subkategori, produk reguler, dan paket bundling. Gunakan filter atau pencarian pada daftar produk, lalu buka detail untuk memilih ID varian sebelum menambahkan ke keranjang. Harga ada pada varian. Paket dibentuk dari varian komponen dan kuantitas per komponen. Kapasitas bundle mengikuti stok komponen yang dibutuhkan.

Di panel admin, kelola kategori dan subkategori sebelum membuat produk. Tambahkan varian berisi nama, SKU, harga, dan stok. Kelola paket dari menu bundling. Penghapusan data yang masih dipakai transaksi atau komponen mengikuti pemeriksaan relasi di panel. Gambar publik disajikan melalui endpoint media atau direktori storage publik.
